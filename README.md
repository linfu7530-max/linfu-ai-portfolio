# Linfu AI Portfolio

一个极简风格的个人作品站，面向 AI 设计与销售增长场景展示。  
网站聚焦个人定位、项目案例（Problem / Solution / Result）以及中英文双语内容展示。

## Live Site

- Coming soon: `https://your-vercel-domain.vercel.app`

## About

Linfu 是一名 AI 设计师，拥有 7 年电话车险销售经验。  
这个站点用于展示如何把一线销售经验沉淀为可规模化的 AI 产品能力。

## Highlights

- 极简风格页面，内容驱动的个人叙事
- 项目案例采用 `Problem / Solution / Result` 结构
- 项目详情页路由：`/projects/:slug`
- 中英文一键切换（通过 URL 参数保留语言状态）
- 首页 CTA（下载简历 / 微信联系 / 快速沟通）

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

推荐使用 Vercel 部署：

1. 导入 GitHub 仓库 `linfu-ai-portfolio`
2. 保持默认构建配置（Vite）
3. 点击 Deploy
